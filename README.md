# โครงงานปลั๊กอัจฉริยะและระบบติดตามการใช้พลังงาน 

โครงงานนี้คือระบบปลั๊กอัจฉริยะที่พัฒนาด้วยบอร์ด ESP32 เพื่อควบคุมการเปิด-ปิดเครื่องใช้ไฟฟ้า โหลดหลอดไฟ ผ่านอินเทอร์เน็ต MQTT พร้อมระบบวัดการใช้พลังงานด้วยเซนเซอร์ PZEM-004T และมีฟีเจอร์ตั้งเวลาทำงานอัตโนมัติ

## ฟีเจอร์หลัก 
* Manual Control: ควบคุมการเปิด-ปิดได้จากสวิตช์ปุ่มกดที่ตัวเครื่อง (มีระบบ Debounce ป้องกันปุ่มค้าง)
* MQTT Remote Control: สั่งงานจากระยะไกลและดูข้อมูลแบบ Real-time ผ่านแอปพลิเคชันหรือ Dashboard
* Energy Monitoring: วัดค่าแรงดัน (V), กระแส (A), กำลังไฟฟ้า (W) และพลังงานสะสม (kWh)
* NTP Scheduling: ตั้งเวลาเปิด-ปิดล่วงหน้าตามเวลาจริง (GMT+7) ด้วยรูปแบบ JSON
* Auto Cut-off (Energy Saving): ระบบตัดไฟอัตโนมัติหากพบว่ากินกระแสต่ำกว่าเกณฑ์ (5W) ต่อเนื่องเกิน 30 วินาที

---

## อุปกรณ์ที่ใช้ 
1. บอร์ด ESP32 Development Board
2. เซนเซอร์วัดพลังงาน PZEM-004T V3.0 (UART)
3. โมดูลรีเลย์ 1-Channel (Opto-isolated) - ต่อใช้งานแบบ NC (Normally Closed)
4. ไมโครสวิตช์ (Push Button) 
5. หลอดไฟ / โหลดไฟฟ้า สำหรับทดสอบ

---

## Wiring Diagram

1. ESP32 <--> PZEM-004T (การสื่อสาร UART):
* 5V (VIN) -> VCC
* GND -> GND
* GPIO 16 (RX2) -> TX ของ PZEM
* GPIO 17 (TX2) -> RX ของ PZEM

2. ESP32 <--> Relay Module (ควบคุมโหลด):
* 3.3V หรือ 5V -> VCC
* GND -> GND
* GPIO 4 -> IN (สั่งงานด้วยลอจิก LOW = ทำงาน)

3. ESP32 <--> Push Button (ปุ่มกด):
* GPIO 32 -> ขาข้างหนึ่งของสวิตช์ (กำหนดโหมดเป็น INPUT_PULLUP)
* GND -> ขาอีกข้างของสวิตช์

4. ภาคจ่ายไฟ AC (220V):
* ลากสายไฟ Line (L) ของปลั๊กผ่านหน้าสัมผัส NC (Normally Closed) และ COM ของรีเลย์ก่อนเข้าสู่หลอดไฟ

## Installation & Setup

1. ติดตั้ง Arduino IDE และเพิ่มบอร์ด ESP32 ผ่าน Board Manager
2. ดาวน์โหลดและติดตั้งไลบรารีที่จำเป็นผ่าน Library Manager:
   * PubSubClient (สำหรับเชื่อมต่อ MQTT Broker)
   * PZEM004Tv30 (สำหรับอ่านค่าเซนเซอร์)
   * ArduinoJson (สำหรับจัดการข้อมูล JSON ขาเข้า/ขาออก)
3. เปิดไฟล์ .ino และแก้ไขตั้งค่าต่อไปนี้ให้ตรงกับเครือข่าย:
